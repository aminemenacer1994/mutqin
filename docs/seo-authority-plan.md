# Mutqin authority and backlink plan (white-hat)

Phase 5 is **strategy only**. Do not buy links, spin PBNs, auto-comment, or ship spam “directory submitter” features. Related: [Technical SEO](seo.md), [Keyword map](seo-keyword-map.md).

**Goal:** Earn a small number of **relevant, editorial** mentions and links from people who actually teach, study, or write about Hifz — because Mutqin is useful between lessons, not because a ranking dashboard asked for more referring domains.

**Hosts:** Home and waiting list live on `https://mutqin.ai`. Most linkable pages today canonicalise to `https://app.mutqin.ai` (tools, features, guides). In outreach, paste the **canonical URL** from the page (or `sitemap.xml`). If the marketing host later serves `/tools` and `/guides`, update the tracker; do not leave two competing public URLs for the same asset.

**Voice that must not be broken:** Mutqin supports practice between lessons. It does not replace a teacher, does not grant ijāzah, and does not invent completion dates, testimonials, or recitation accuracy claims.

---

## Principles

1. **Relevance over volume.** One link from a Hifz school resource page beats fifty generic “top apps” farms.
2. **Give first.** Lead with a free tool or a guide a teacher can hand to students. Ask for a listing only after they have used it.
3. **Human outreach.** Named recipient, specific asset, one clear ask. No mass AI mail-merge, no identical pitches.
4. **Describe, do not hype.** No “best Quran app”, no fake ratings, no comparison tables you have not verified.
5. **Track relationships, not DR.** The tracker below is a CRM-lite. Domain Rating is not a KPI.

### Never do

- Buy bulk backlinks, “guest post packages”, or expired-domain networks (PBNs)
- Automated blog comments, forum signature spam, or wiki vandalism
- Spam directories, article spinners, or Fiverr link sellers
- Fake reviews (Play Store, Trustpilot, “testimonial” pages, or invented student quotes)
- Mass AI outreach or scraped email blasts
- Irrelevant guest-post farms (finance, CBD, casinos, generic “education blogs”)
- Link exchanges as a programme (“we’ll link you if you link us”)
- Pressuring teachers for a `.edu` or mosque site link as payment for using the product

### Tier C — assets to earn later (do not pitch as if they exist)

Only build when the piece would be **cited without Mutqin in the title**. Examples that would be legitimate:

- A **methods note** on how Mutqin counts ayahs, Madani pages, and Juz bounds (already used in the public calculator) — not a fake “study of 10,000 huffaz”.
- A **teacher one-pager** (PDF or HTML) for ḥalaqah: suggested sitting length, what the public test does and does not grade.
- An honest **Mutashābihāt practice worksheet** that points at the guide + future public explorer (`/tools/similar-ayahs` is not live).
- Original **product-honest** writing: how a recitation checker can mis-hear, why the public test has no microphone, how privacy treats audio (`/privacy`).

Do **not** manufacture “Quran memorization research” with invented statistics, completion rates, or survey results you did not run.

## Tracking system

Keep one spreadsheet (or Notion database). **Do not** automate outreach from it.

### Columns

| Column | Values | Notes |
|--------|--------|--------|
| Target | Organisation or person | One row per relationship |
| Type | Teacher / school / ISoc / blogger / … | Matches categories above |
| Site URL | Their page | The page you hope might cite Mutqin |
| Contact | Named person + channel | Email, not a no-reply inbox when possible |
| Asset offered | Canonical Mutqin URL | One primary asset |
| Status | See pipeline below | Single current state |
| Contacted | Date | First genuine message |
| Replied | Date / none | Even a “no” is a reply — stop or wait |
| Link obtained | URL of **their** page + `nofollow`? | Record the live href |
| Follow-up | Date due / done | Max **two** follow-ups, 10–14 days apart |
| Notes | Free text | What they cared about; do not store student PII |
| Do not contact | Yes/No | Respect unsubscribe and silence after two follows |

### Pipeline (use exactly these states)

`Target → Contacted → Replied → Link obtained → Follow-up`

How to move:

1. **Target** — researched, named contact, asset chosen, not yet messaged.
2. **Contacted** — first human message sent.
3. **Replied** — they answered (yes, no, or “try it”). If no reply after two follow-ups, archive as **Closed-no reply** (add that as a note; do not keep poking).
4. **Link obtained** — public href to a Mutqin canonical URL. Paste the source URL. Screenshot optional.
5. **Follow-up** — either (a) scheduled nudge while still **Contacted**, or (b) thank-you / correction after a link goes live (broken URL, wrong host, overclaiming). After a live link, follow-up means **stewardship**, not “can you add more links”.

Optional extra states in Notes only: `Closed-no`, `Closed-no reply`, `In use no link` (they use Mutqin but will not list it — that is still a win).

### Cadence and volume

- **Cap:** about **8–12 new Contacted rows per week** once the list is warm, fewer at the start. If you need a script to hit 100, you are doing it wrong.
- **Follow-up:** two times maximum; then stop.
- **Monthly review:** count conversations and *useful* citations, not raw referring domains. Drop any channel that only produces spammy lists.

## Social: discovery, not ranking hacks

Mutqin already points people to Instagram, Facebook, LinkedIn, TikTok, and X from the site footer. Treat those as **distribution and trust**, not as PageRank pipes. Most social hrefs are nofollowed or ignored as ranking signals. They still help humans find the tools, which is how **editorial** links happen later.

### What social is for

- Put the **same canonical tool URL** in bios, pinned posts, and video descriptions (planner, test, Find an ayah).
- Show a real sitting: short range, hide text, quiet quiz — matching the guides.
- Repeat the teacher-safe line so creators do not overclaim for you.
- LinkedIn: teachers, school admins, Muslim edtech peers — long-form of `/guides/*`, not growth-hack carousels.
- Instagram / TikTok: 15–45s of the public test or Find an ayah; link in bio / description to `/tools/...`.
- Facebook: ḥalaqah groups **only if you are a member and add value**; no link-drop raids.
- Future YouTube: 5–8 min “how to plan a week of Hifz” pointing at the planner + revision guide. Chapters + description URL. Transcripts help **people** and can be cited; they are not a backlink factory.

### What social is not for

- Buying comments or engagement pods
- “Drop your link” threads
- Treating a TikTok view spike as an SEO win
- Cross-posting identical CTA spam to all five networks daily
- YouTube titles like “AI proves your Hifz”

### Lightweight content map (reuse site copy; do not invent studies)

| Channel | Recurring idea | Destination |
|---------|----------------|-------------|
| Instagram / TikTok | “Three ayahs a day — see the calendar” | Planner |
| Instagram / TikTok | “Check a short range with no mic” | Memorization test |
| Instagram / YouTube | “Type the words you remember” | Find an ayah |
| LinkedIn | “Why we do not replace the teacher” | `/our-mission`, `/privacy` |
| Facebook / newsletter | One guide excerpt + one tool | Matching `/guides/*` |
| YouTube (future) | Murajaah vs new lesson | `/guides/hifz-revision` |

If a creator wants a unique landing URL, give them the existing canonical page plus UTM on **analytics events you already use** (`utm_source`, `utm_medium`, `utm_campaign`). Do not clone thin campaign pages.

## 90-day plan

Assume one owner (founder or a comms lead) at a few hours per week. Stretch only if conversations are genuine.

### Days 1–14 — foundation

- Freeze **three** default pitches: (1) planner for teachers/ISocs, (2) test for revision posts, (3) Find an ayah for “I forgot the surah”.
- Build the tracker. Seed **25 P1 targets** with named contacts (teachers, 2–3 schools, 5 ISocs, 5 Hifz blogs). Quality of research over list length.
- Confirm Search Console coverage of `/tools/*` and `/guides/*` (see [seo.md](seo.md)). Fix any wrong-host links you already know about.
- Record 3–4 short demos of the public tools for email and social (no fake student faces, no fabricated quotes).
- Social bios: single link to `/tools` (or Linktree that lists the four tools with canonical URLs).

### Days 15–45 — P1 conversations

- Contact **2–4 people per week** (not 40). Personal first lines only.
- Offer a live walkthrough to any teacher or ISoc officer who replies.
- Publish 1 LinkedIn note and 2 short IG/TikTok demos **of the same assets you are pitching** (consistency, not volume).
- Log every reply. Convert “we used it” into a **resource-list** ask only when it feels natural.
- **Do not** start guest-post hunting.

**Exit check:** several real conversations; at least one organisation using a tool with students, with or without a link.

### Days 46–75 — editorial and lists

- Blogger unlinked-mention pass: search for existing Mutqin or “Hifz app” round-ups; correct facts; ask for a link only where the page is already about Hifz tools.
- 5–8 newsletters / Muslim tech writers: one asset, privacy link if they mention AI.
- 3–5 legitimate resource pages (chaplaincy, school, NGO). Skip anything that smells like a paid directory.
- One YouTube outline (even if unpublished): techniques + planner, ready for a teacher collaboration.

**Exit check:** a few **indexable** citations to `/tools` or `/guides`, not profile-page nofollows only.

### Days 76–90 — steward and decide

- Second follow-ups only where Status is still **Contacted**.
- Thank anyone who linked; if they overclaimed (ijāzah, “AI grades tajwīd”), ask them to tone it down — brand safety beats a toxic link.
- Review: conversations, in-use-without-link, editorial links, wasted pitches. Cut any category that produced only spammy lists.
- Decide **one** Tier C asset for the next quarter (teacher one-pager **or** methods note on counts) — only if someone asked for it.
- Social: keep the demo cadence; do not “scale content” for its own sake.

**Success for 90 days (realistic):** a handful of relevant links or newsletter mentions; several teachers/ISocs actually using a public tool; zero paid-link residue; copy still teacher-safe.

## Message skeleton (human, not a mail-merge)

Use as a checklist, rewrite every time:

1. Why you are writing **to them** (their class, their article, their resource list).
2. What Mutqin is in one sentence (companion between lessons).
3. **One** URL to try (tool or guide).
4. What it does **not** do (no ijāzah, no mic on the public test, etc.).
5. A small ask: try it / 15-minute call / consider listing if it helps students.
6. Easy no.

Never attach a “100 backlink opportunities” spreadsheet to the email.
