# Group G — Resources, responsive and cross-browser verification

**Depends on:** Core preview pages from Groups B–D.

## Goal

Add `/preview/resources` (guides, links, downloads as needed) and verify marketing quality across viewports and browsers.

## Deliverables

1. Resources route and content (editorial, not a card grid dump)
2. Responsive pass on `/preview` at 390, 768, 1280, 1440px (document screenshots)
3. Accessibility spot-check: landmarks, focus, contrast on new sections
4. Optional BrowserStack or Playwright evidence recorded in progress file

## Acceptance criteria

- No horizontal overflow or clipped preview browser shots on mobile
- Dark and light themes readable on new sections

## Out of scope

Full WCAG audit sign-off (note limitations honestly).
